KINO 1.8 — SIMPLER MENU AND LAPTOP LAYOUT

The title screen now uses the game name, Solo Zombies, Play and Settings.
The pause screen uses Resume, New game and Settings. The promotional tagline,
decorative program card and large theatrical framing were removed. Existing
credits remain. Eight essential controls stay visible, including Q to aim and
Left mouse / Z to fire; complete controls remain in Settings.

The menu is sized for smaller laptop windows and supports the existing text-size
setting. Its action buttons, status and essential controls enlarge with the
selected text size. Keyboard focus is outlined clearly. The menu has a named
heading and a semantic controls list; loading/status updates are announced.
All existing game/settings IDs and loading/retry hooks are preserved.

The settings component, maintained in desktop-settings.js, supplies dialog
semantics, contained Tab navigation, Escape-to-close and focus return. Closing
Settings leaves an active run paused. The panel scrolls vertically on narrow
windows. Its background is opaque, avoiding faint menu text behind labels and
the unnecessary laptop compositor work of the previous background blur.

Executed menu verification
Eight real headless-Chrome checks passed with zero script, shader or asset
errors. The checks cover 1280x800 title/pause, 1440x900 pause/settings, keyboard
Play/Resume, focus order and modal containment, all previous settings, and the
140% Larger text setting. At 1280x800, all menu actions and essential controls
fit without scrolling even at 140%. At 560x660, the settings panel scrolls
vertically without horizontal overflow, and the keyboard can reach Done.

Scope
These are automated browser layout/input checks at the named CSS viewport
sizes on the development Mac. They do not certify a physical MacBook, Intel
GPU, trackpad gesture comfort, screen reader behavior, physical peripherals,
or sustained laptop performance. Separate packaging/performance reports state
the machines and runtime actually checked.
